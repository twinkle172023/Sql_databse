Why Extension-Only Validation is Insecure

When a server relies solely on filename.endswith('.pdf'), an attacker can rename a Python script (e.g. hello.py to hello.pdf). The server accepts it because it trusts the extension. In a real-world insecure system, if a background worker or server later attempts to execute or evaluate the file, malicious code runs. In this laboratory, uploaded files are stored strictly as inert binary data with UUID filenames and are NEVER executed.
