1. File Upload Subsystem

Demonstrates document storage using SQLite metadata. Files are stored as inert data with generated UUIDs and are never executed.

  • Supported: PDF, DOC, DOCX, PPT, PPTX, TXT, JPG, PNG
  • Files stored as inert data in uploads/
  • Metadata logged into documents table in database.db

2. SQL Injection Demonstration

Generates raw vulnerable SQL queries via string interpolation alongside safe parameterized equivalents.

  • Vulnerable Mode: SELECT ... WHERE username = '{input}'
  • Secure Mode: SELECT ... WHERE username = ?
  • Export button to pass query into your Compiler project

Architecture Pipeline

User Upload  ──>  Save to uploads/ (UUID)  ──>  Store in documents table  ──>  Display in Documents Table

User Input   ──>  SQL Interpolation (Vulnerable)  ──>  Altered Query AST  ──>  Compiler Detects Vulnerable SQL
             ──>  Parameterized Query (Secure)    ──>  Literal Data AST   ──>  Compiler Verifies Safe Pattern
